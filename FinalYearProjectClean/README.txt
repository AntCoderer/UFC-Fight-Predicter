this project was made in visual studio code for best results use that

Install dependencies:

pip install -r requirements.txt


Run Order:


please run

statsMaker.py first

then you may run 

logisticMethod
gradientBoost1
LogisticNonBias
logisticScript
randomForest
xgboostScript


UI section:

to run the UI please make sure you run LogisticNonBias.py first for best results

how to run:

in VSCode - open a terminal, make sure you are in the projects folder in the terminal and run:
streamlit run ui/VisualPass.py

how to run in cmd:

navigate to the folder for you computer

example:

cd C:\Users\YourName\Documents\FinalYearProjectClean

make sure requirments are installed if not already

then run: streamlit run ui/VisualPass.py


how to use UI:

you should be brought to your browser

you can select gender weigh class and time and finally fighters

for best testing choose a fight just after ufc 308
